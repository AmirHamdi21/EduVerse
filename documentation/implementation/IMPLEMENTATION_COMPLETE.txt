DEVICE BREAKPOINTS:
  • Mobile:  < 600dp  (scale 1.0x)
  • Tablet:  600-900dp (scale 1.1x)
  • Desktop: > 900dp  (scale 1.2x)

RESPONSIVE VALUES:
  • Padding/Margin:   p4, p8, p12, p16, p20, p24, p32, p40, p48
  • Font Sizes:       fontSize12 through fontSize32
  • Border Radius:    radius4, radius8, radius12 through radius24
  • Icon Sizes:       iconSmall, iconMedium, iconLarge, iconExtraLarge
  • Buttons:          buttonHeight, inputHeight
  • Content:          contentPadding, horizontalPadding, maxContainerWidth

SAFE AREA SUPPORT:
  • safeAreaTop, safeAreaBottom
  • safePadding, hasNotch detection
  • Notch-aware positioning

================================================================================
                            USAGE EXAMPLE
================================================================================

In any screen's build method:

  @override
  Widget build(BuildContext context) {
    final responsive = context.responsive;
    
    return Scaffold(
      body: Padding(
        padding: EdgeInsets.all(responsive.p24),
        child: Column(
          children: [
            Text(
              'Responsive Text',
              style: TextStyle(fontSize: responsive.fontSize24),
            ),
            SizedBox(height: responsive.p16),
            Container(
              height: responsive.buttonHeight,
              child: ElevatedButton(...),
            ),
          ],
        ),
      ),
    );
  }
