### After
```
main.dart
├── ThemeBloc (manages dark/light mode)
├── AuthBloc (manages authentication)
└── LanguageCubit (manages language switching)
    └── Emits Locale
        └── MaterialApp switches localization
            └── AppLocalizations.of(context) returns correct translations
```

## How Language Switching Works

1. **User Action**: Taps "Arabic" in settings
2. **LanguageCubit**: Receives `.changeLanguage('ar')`
3. **Persistence**: Saves to SharedPreferences: `{'selected_locale': 'ar'}`
4. **Emit**: `emit(Locale('ar'))`
5. **BlocBuilder**: Triggers rebuild with new locale
6. **Flutter**: Applies localization for 'ar'
7. **UI Update**: All `AppLocalizations.of(context)` calls return Arabic strings
8. **App Restart**: Next launch loads saved locale and starts in Arabic

## Usage Pattern

### Adding a New Translation

1. **Edit ARB files**:
```json
// lib/l10n/app_en.arb
{
  "@@locale": "en",
  "myNewKey": "My English Text"
}

// lib/l10n/app_ar.arb
{
  "@@locale": "ar",
  "myNewKey": "النص العربي الخاص بي"
}
```

2. **Regenerate**:
```bash
flutter gen-l10n
```

3. **Use in Code**:
```dart
Text(AppLocalizations.of(context)!.myNewKey);
```

### Using in Widgets

```dart
import 'package:edu_verse/generated_l10n/app_localizations.dart';

class MyWidget extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final l = AppLocalizations.of(context)!;
    
    return Text(l.hello);  // "Hello" or "مرحبا" based on locale
  }
}
```

### Changing Language

```dart
// From any widget
context.read<LanguageCubit>().changeLanguage('ar');
context.read<LanguageCubit>().changeLanguage('en');

// Get current language
String current = context.read<LanguageCubit>().getCurrentLanguage();
```
